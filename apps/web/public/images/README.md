# Images and icons

All site images and icons live here. Data will come from the server/CMS later; this folder holds static assets.

- **Logo:** Place `screenriot-logo.png` here (used in Header and Footer). If it was at project root `public/screenriot-logo.png`, move it to `public/images/screenriot-logo.png`.
- **icons/** — SVG icons (search, share, user, etc.) used in components.
